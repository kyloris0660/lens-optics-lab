# 镜头光学图解与交互实验室

**看见光线，读懂镜头。** 面向摄影爱好者和光学初学者的中文教学项目，把概念解释、光路示意、数值计算和成像对照放在一起。

这个项目从几个问题出发：镜头为什么需要多组多片？非球面究竟改善什么？像差、球差、色散和色差有什么关系？增加一片镜片为什么不一定让成像更好？

**[在线使用 →](https://kyloris0660.github.io/lens-optics-lab/)** · **[系统教程](https://kyloris0660.github.io/lens-optics-lab/guide.html)** · **[镜片实验室](https://kyloris0660.github.io/lens-optics-lab/lab.html)** · **[下载离线版](https://kyloris0660.github.io/lens-optics-lab/downloads/lens-optics-offline.zip)**

纯静态网页，无账号、无广告、无统计追踪、无运行时第三方依赖。所有图像和计算都可以离线使用。首次部署方式见 [DEPLOY.md](DEPLOY.md)；GitHub Pages 首次构建完成前，上方网站链接可能暂时返回 404。

## 你能学到什么

| 内容 | 原理与直观体验 |
| --- | --- |
| 成像基础 | 折射、焦距、视角、物距与像距、画幅、放大倍率、透视与拍摄距离 |
| 光圈与合焦 | f 值、入瞳、景深、弥散圆、超焦距、焦深、呼吸效应、焦点漂移 |
| 单色像差 | 球差、彗差、像散、场曲、畸变，理解“点变糊”和“位置变了”的区别 |
| 色散与色差 | 材料色散、阿贝数、轴向/横向色差、消色差双片、ED 与非球面的分工 |
| 波动光学 | 波前、点扩散函数 PSF、衍射、艾里斑、Strehl 比、MTF 与像素采样 |
| 实际画质 | 暗角、口径蚀、焦外、洋葱圈、眩光、鬼影、镀膜、偏心与制造公差 |
| 镜头设计 | 组与片、胶合、材料/曲率/间距/面形的组合，以及片数、画质和体积之间的取舍 |

### 01 · 系统教程

按照“成像基础 → 像差 → 波动与评价 → 实际镜头”的顺序学习，包含：

- 焦距、光圈、物距和弥散圆交互计算器。
- **19 组**波前、PSF 和测试靶成像对照；所有组共用明确的显示尺度。
- 两种光学玻璃的材料色散曲线。
- 畸变、场曲、暗角、轴向/横向色差与焦外特征示意。
- 衍射与 MTF 计算器，可调整波长、f 值与像素尺寸。
- 术语解释、常见误区、模型限制和一手参考资料。

### 02 · 镜片组合实验室

采用三维几何光线追迹，在同一个界面观察结构、光路、焦点、点列图和局部成像：

- 在**单片球面、单片非球面、消色差双胶合**之间切换。
- 改变孔径、视场角、光源、非球面常数、空气间隔与传感器位置。
- 尝试拆掉负片、替换玻璃材料或额外添加镜片。
- 自动寻找几何 RMS 最小的焦面，或锁定像面后重新对焦。
- 保存当前对照，查看改动前后的指标与光斑变化。

**建议的第一次体验：**先比较球面和非球面在单色光下的表现，再切到三色光；随后观察消色差双片，尝试把两片改成同一种玻璃。这样可以直接理解“校正球差”和“校正色差”的不同。

## 模型与准确性

项目明确区分三种内容，避免把教学画面误当作真实镜头测量：

| 内容 | 方法 | 能说明什么 / 限制 |
| --- | --- | --- |
| 几何实验室 | 曲面逐面求交、矢量 Snell 定律、Sellmeier 色散、几何 RMS 焦面最小化 | 展示指定教学处方的光路与几何像差；不含衍射、镀膜、多次反射与制造公差 |
| 傅里叶像差图鉴 | 标量 Fraunhofer 衍射、均匀圆形入瞳、指定 Zernike 波前、非相干强度卷积 | 展示指定波前如何影响点像和图像；不由实验室当前镜片处方直接生成 |
| 特征辨认示意 | SVG / Canvas 绘图和简化映射 | 帮助辨认畸变、场曲、暗角、焦外、眩光等现象；不是某支镜头的预测或实拍 |

几何实验室默认物点在无限远。三色模式使用 486.1、587.6、656.3 nm 等权重，不等于完整连续白光或某台相机的色彩响应。非球面无球差特例只针对特定面形、轴上物点与设计波长。

“镜片更多”本身不是画质指标；改变结构也可能改变焦距、f 值与视场，因此不能把任意两组数字当作严格同条件的镜头横评。

计算基准、验证范围和未验证事项见 [数值验证记录](src/validation.md)，图鉴元数据见 [model.json](src/guide-assets/model.json)。理论和材料来源见 [THIRD_PARTY.md](THIRD_PARTY.md) 及网页内的参考资料。

## 离线使用

**最简单：**下载上方离线 ZIP，完整解压，双击 `index.html`，用现代桌面浏览器打开。

也可以在 GitHub 点击 **Code → Download ZIP**，解压仓库后双击 `docs/index.html`。教程、图像与交互计算全部保存在本地，不需要 Node.js、Python 或服务器。只有主动打开外部参考文献链接时需要网络。

请保留整个文件夹，不要只复制某一个 HTML 文件。手机文件预览器可能不运行 JavaScript，建议用桌面浏览器。

## 开发与复现

源码在 `src/`，`docs/` 是可直接打开、可由 GitHub Pages 发布的构建结果。通常只编辑源码，再生成网页，避免手工修改两份文件。

```bash
git clone https://github.com/kyloris0660/lens-optics-lab.git
cd lens-optics-lab

# 只使用 Python 3 标准库：构建网页与离线 ZIP
python build.py

# 只使用 Node.js 内置模块：验证光线追迹与解析公式
node validate.mjs
node validate-guide.mjs

# 校验资源、跳转、离线依赖与归档完整性
python check-build.py
```

在部分系统中请用 `python3` 代替 `python`。建议使用 Python 3.11+、Node.js 20+。

重新生成傅里叶图鉴才需要安装科学计算依赖；普通构建与阅读不需要：

```bash
python -m pip install -r requirements-dev.txt
python generate-guide.py
python build.py
node validate-guide.mjs
python check-build.py
```

项目已经提交生成好的图像。跨平台或不同依赖版本重新生成的图像可能存在像素级差异，应以模型元数据和数值断言核对结果。
