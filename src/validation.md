## 基准结果

无限远轴上物点，入射直径 20 mm，分别按当前光谱自动对焦；数值为几何 RMS 半径，不是含衍射的真实点扩散函数。

| 结构 | 587.6 nm 单色 / μm | 三波长等权 / μm | d 线有效焦距 / mm |
|---|---:|---:|---:|
| 单片球面 | 79.95949 | 92.70173 | 96.74952 |
| 单片非球面，k = -n_d² | 数值精度内为 0 | 46.65639 | 96.74952 |
| 数值设计双胶合 | 1.49697 | 4.07093 | 100.00000 |

单片红蓝近轴焦点差 1.499451 mm；双胶合在模型精度内重合，但 d 线仍有二级光谱与全孔径残余像差。数字不能用于商业镜头性能排名。

## 已执行

- SCHOTT 材料折射率复核：N-BK7 n_d=1.51679844，N-F2 n_d=1.62004984，与资料表五位小数一致。
- 单片近轴焦距与解析值 |R|/(n-1) 一致。
- 平面入射、曲面出射、k=-n² 的解析无球差特例：轴上指定波长 RMS < 1e-9 mm，焦点与解析值一致。
- 非球面三色光残余色差、双胶合 F/C 近轴消色差、同材料替换、缩光圈趋势复核。
- 自动焦面与左右 0.1 mm 比较，确认 RMS 最小化；三维光线旋转对称性复核。
- 198 组代表性边界条件：三结构、直径 2/10/20 mm、视场 0/2.5/5°、单色/三色、拆片/加片/换材料/间距/面形，均为有限数值、正向焦点，采样通光超过 99%。
- 基准采样加密：每波长 384 → 1536 条。非零 RMS 基准最大相对变化约 0.0017%。
- JavaScript 语法、HTML 唯一 ID、静态资源引用检查。
- 在 Node + 原生 Canvas 的轻量 DOM 测试环境中执行界面事件：结构切换、光谱、对照、拆片、固定焦面、重新对焦、重置、四个引导实验、移动端展开；通过。
- 原生 Canvas 渲染并检查点列图、焦点图、靶图卷积。该检查不等同于浏览器整页检查。
